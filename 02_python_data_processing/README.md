## Data
- `data/titanic.csv` – Kaggle / Data Science Dojo Titanic training set (891 passengers)
- `data/sales.csv`, `employees_messy.csv`, `daily_temperature.csv`, `customer_reviews.txt` – practice datasets, regenerated by `python data/generate_datasets.py` (seeded, so the output is identical every time)

`SexCode` (used in MP5) is not in the Kaggle file, so it is derived as female = 1, male = 0.

Tests: `python -m unittest discover -s tests -v`
